# Coheleth's Next.Js 16 Boilerplate

This is a simple blog next.js 16 boilerplate.

<!-- Demo: https://coheleths-next-boilerplate.vercel.app -->

## Features

- Tailwind support
- Typescript support
- Basic SEO
  - Configurable metadata
  - Sitemap
  - Robots.txt
- Basic components:
  - Navigation bar
  - Search bar
  - Mobile navigation menu
- Blog:
  - Markdown posts
  - Syntax highlighting with Prism
  - Pagination
  - Basic search
  - Tags

## Getting Started

First, install dependencies:

```bash
$ yarn install
```

Then run in development mode:

```bash
$ yarn dev
```
